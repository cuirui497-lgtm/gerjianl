# 崔睿 · AI 视觉设计师作品集

零依赖 HTML / CSS / JavaScript，可直接打开 index.html，也可用本地服务预览。

## 本地启动

在此目录运行 `python3 -m http.server 5173`，浏览器访问 http://localhost:5173。

- index.html：独立动态视觉入口，点击进入 portfolio.html。
- portfolio.html：作品集主页。
- style.css：PC / 移动端样式与设计变量。
- projects.js：项目图集数据；app.js：筛选、详情、联系交互。
- visual.js：临时动态视觉，可替换为后续提供的原始效果代码。
- assets：由原始 PNG 转换的 WebP 素材，不修改源素材。

## 内容结构与设计规范

视觉入口 → Hero → 个人介绍与工作经历 → 精选作品 → 能力优势 → 联系收尾。

定位：AI 视觉设计师；以 AIGC、机器人交互为特色，辅以多端产品、复杂系统与三维设计。
简历事实、工作时间、联系方式取自提供图片；介绍及能力段落为结合素材补写的网页文案，待本人审定。08 为素材目录中的项目集合数，04 为简历工作经历数，不代表商业绩效。

颜色：背景 #0d0e10，卡片 #151619，正文 #efeee9，次级文字 #96969b，强调 #ff7547。
字体：系统无衬线中文，英文数字以 Arial / Courier New 辅助。桌面标题 40–76px，章节标题 30–48px，正文 13–15px。
布局：桌面左右 5.5% 留白，项目两列、优势四列；900px 以下优势两列；600px 以下单列，边距 6%，导航缩减，触控操作保留。页面最大内容宽 1700px。
交互：锚点导航、项目分类筛选、原图详情、Esc 关闭、邮件和电话链接、复制微信号。尊重减少动态效果系统设置。
